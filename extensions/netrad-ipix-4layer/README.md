# NetRAD and IPIX — four-layer score-level reproducibility

**Research author:** Hamzeh Ghahramani.

This subtree contains the four-layer **per-window-optimized** experiments, separate from both the
frozen two-layer IPIX model and the recovered six-layer IPIX checkpoint. It contains 21 NetRAD
acquisition score JSONs, eight IPIX acquisition summaries, five and three numeric CSV outputs,
respectively, scripts and tests. No raw IPIX/NetRAD recordings are included.

```bash
python verify_release_candidate.py
(cd NetRAD && python -m pytest tests -q && python repro_norival_du.py)
(cd IPIX && python -m pytest tests -q && python repro_norival_du_ipix.py)
python verify_release_candidate.py
```

The five NetRAD plus three IPIX numerical CSVs can be regenerated byte-for-byte. NetRAD calibrated
empirical Pfa=0.01 (4/400 H0 calibration windows) is not an independent CFAR demonstration.
IPIX 'ROC-style' figures are visualizations of operating-point summaries, not per-score ROC estimates.
Some compared baselines have different input-channel configurations, as specified in
`docs/PROTOCOLS_AND_FAIRNESS.md`. Inference-speed claims from the frozen two-layer model do not
transfer automatically to the per-window four-layer model.

A `cerbm.py` shared-code helper remains for the historical CCEBM implementation, but no CERBM or
DU-CERBM detector results are published here.
