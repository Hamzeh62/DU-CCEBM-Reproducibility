## Which experiments are covered?

This software deposit groups *distinct* frozen two-layer IPIX, four-layer per-window NetRAD/IPIX,
and frozen six-layer IPIX experiments. It is not a demonstration that any separate older manuscript,
including earlier LI-SOBI/LI-CERBM experiments, is reproduced in full by this package.

The raw IPIX/NetRAD recordings are not included. Four-layer outputs are reproducible from the
archived derived score snapshots, while six-layer inference against the original raw IPIX
recordings was independently replayed before publication. The archived v1.0.0 snapshot is fixed;
GitHub documentation updates after tagging do not change the archived software.
