# DU-CCEBM v1.0.0 — initial reproducibility release (historical draft)

> Historical pre-release draft retained for provenance. The release is now published on Zenodo:
> https://doi.org/10.5281/zenodo.23416237

Sole author: Hamzeh Ghahramani.

New public, single-commit research-software distribution. Includes a frozen two-layer IPIX model,
a separate four-layer per-window-optimized NetRAD/IPIX experiment and a separately recovered
six-layer IPIX model with its genuine frozen checkpoint and full archived score evidence.
Eight four-layer numeric CSV tables reproduce exactly. Six-layer checkpoint re-scoring against
14 original IPIX CDF recordings independently reproduced 240 mixed + 22,416 genuine-only scores.
The bundled six-layer reference does not establish fresh full retraining. Original raw recordings
and historic publisher-uncertain visual assets are not distributed.
