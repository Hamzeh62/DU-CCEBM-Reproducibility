# Data availability and redistribution

Raw IPIX radar CDF recordings are not included in this public-software staging
package. Obtain them from the rightful distributor under applicable terms.
After obtaining the data, set the path using `--data-dir`; generated derived
scores and plotted aggregate values are supplied in `evidence/`.

Before publication verify the canonical current IPIX dataset URL and its reuse
policy; do not assume that possession of a CDF permits redistribution.
